# 📅 Day 14 – Strings

## String
A sequence of characters enclosed in quotation marks.

## Character
A single letter, number, symbol, or space in a string.

## Index
The position of a character in a string or an item in a list. Indexes start at **0**.

## Positive Index
Counts characters from the beginning of a string.

Example:

```python
name = "Peter"

print(name[0])
```

Output:

```text
P
```

## Negative Index
Counts characters from the end of a string.

Example:

```python
name = "Peter"

print(name[-1])
```

Output:

```text
r
```

## `len()`
Returns the number of characters in a string or the number of items in a collection.

## `.upper()`
Converts all letters in a string to uppercase.

Example:

```python
name = "Peter"

print(name.upper())
```

Output:

```text
PETER
```

## `.lower()`
Converts all letters in a string to lowercase.

Example:

```python
name = "Peter"

print(name.lower())
```

Output:

```text
peter
```

## `.title()`
Capitalizes the first letter of each word in a string.

Example:

```python
name = "peter audu"

print(name.title())
```

Output:

```text
Peter Audu
```

## `.strip()`
Removes spaces from the beginning and end of a string.

Example:

```python
name = "   Peter   "

print(name.strip())
```

Output:

```text
Peter
```

## `in`
Checks whether a character or word exists inside a string.

Example:

```python
name = "Peter"

print("e" in name)
```

Output:

```text
True
```

---

# 💡 Day 14 Key Takeaways

- Strings are sequences of characters.
- Every character has an index.
- Positive indexes count from the beginning.
- Negative indexes count from the end.
- `len()` counts characters in a string.
- `.upper()` converts text to uppercase.
- `.lower()` converts text to lowercase.
- `.title()` capitalizes the first letter of each word.
- `.strip()` removes unwanted spaces from the beginning and end of a string.
- `in` checks whether text exists inside another string.

# 📅 Day 15 – Dictionaries

## Dictionary
A collection that stores data as **key-value pairs**.

Example:

```python
student = {
    "name": "Peter",
    "age": 24
}
```

---

## Key
A unique identifier used to access a value in a dictionary.

Example:

```python
student["name"]
```

Here:

```text
"name"
```

is the key.

---

## Value
The information stored for a particular key.

Example:

```python
student = {
    "name": "Peter"
}
```

Here:

```text
Peter
```

is the value.

---

## Accessing a Value

Use the key inside square brackets.

Example:

```python
student = {
    "name": "Peter"
}

print(student["name"])
```

Output:

```text
Peter
```

---

## Adding Data

Add a new key-value pair.

Example:

```python
student["course"] = "Mathematics"
```

---

## Updating Data

Change the value of an existing key.

Example:

```python
student["age"] = 25
```

---

## Deleting Data

Use the `del` keyword.

Example:

```python
del student["age"]
```

---

## Looping Through a Dictionary

Loop through the keys.

Example:

```python
for key in student:
    print(key)
```

Loop through the values.

Example:

```python
for key in student:
    print(student[key])
```

---

# 💡 Day 15 Key Takeaways

- Dictionaries store data as key-value pairs.
- Keys are used to access values.
- Every key should be unique.
- Dictionaries make related information easier to organize.
- Values can be added, updated, or deleted.
- Dictionaries can be looped through using a `for` loop.

---

## 🧠 Memory Sentences

Dictionary → Stores data as key-value pairs.

Key → A unique identifier used to access a value.

Value → The information stored for a key.

`dictionary[key]` → Accesses the value for a specific key.

`del` → Removes a key-value pair from a dictionary.

`for key in dictionary:` → Loops through every key in a dictionary.
